# AstralPHP

Some Worst private server for turn based anime game written in PHP.<br>
Inspired by [TeyvatPS (GI)](https://github.com/timing1337/teyvatps)

- ### What does this server have?
nothing, just standing simulator.<br>
made for prod version.

# Usage

- PHP >= 8.1 (must install)
- composer

# Steps
clone this repository, use ```composer require``` and it will install dependencies and type ```php Start.php```

- ## protos?
find yourself or dump and put to data/protos, use ```php build_proto.php```
